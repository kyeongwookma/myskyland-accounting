급여 프로그램 열기

한 달에 한 번, 순서대로

파일을 넣고 확인한 뒤 출력하면 끝입니다

보험 포털 로그인과 파일 다운로드까지만 직접 합니다. 받은 파일은 프로그램이 종류를 구분하고 직원별 금액을 계산합니다.

급여월 열기→파일 넣기→자동 계산 확인→검토·승인→출력·백업→마감
준비

먼저 받을 파일

파일명은 달라도 괜찮습니다. 프로그램이 파일 안의 제목을 보고 구분합니다.

  • 원장이 전달한 시간외·수당 자료 또는 통합산출 XLSX
  • 사회보험 징수포털의 국민연금 XLSX
  • 사회보험 징수포털의 건강보험·장기요양 XLSX
  • 고용산재 토탈서비스의 고용보험 XLSX
  • 해당자가 있으면 국민연금·고용보험 두루누리 지원금 자료

중요: 파일을 열어서 내용을 복사할 필요가 없습니다. 내려받은 XLSX·CSV 파일 그대로 사용합니다.

  1. 1

    1. 시작

    급여월과 지급일을 확인합니다

    1. 상단의 1. 시작을 누릅니다.
    2. 처음 만드는 달이면 새 급여월 만들기를 누릅니다.
    3. 급여월, 지급일, 기관명과 시설명이 맞는지 확인합니다.

    ✓ 화면 제목에 작업할 연도와 월이 맞으면 완료

  2. 2

    2. 자료 가져오기

    받은 파일을 한꺼번에 넣습니다

    1. 상단의 2. 자료 가져오기를 누릅니다.
    2. 점선 상자를 눌러 파일을 선택하거나, 파일들을 상자 위로 끌어놓습니다.
    3. 여러 파일을 한 번에 선택해도 됩니다.
    4. 프로그램이 파일을 읽을 때까지 잠시 기다립니다.

    새 양식이 필요하면: 원장에게 받을 자료는 입력용 CSV 양식 받기를 눌러 만든 양식을 사용할 수 있습니다.

    ✓ 선택 파일·인식 자료·적용 예정 숫자가 나타나면 완료

  3. 3

    가져오기 미리보기

    직원 연결과 변경 내용을 확인합니다

    1. 원본 직원 이름 옆에 맞는 직원이 연결됐는지 봅니다.
    2. 노란 확인사항이 있으면 연결할 직원을 직접 선택합니다.
    3. 퇴사자나 과거 직원은 적용하지 않음 그대로 둡니다.
    4. 다른 급여월 경고가 나오면 현재 작업 월이 맞는지 다시 확인합니다.
    5. 문제가 없으면 선택한 자료 적용을 누릅니다.

    새 직원으로 추가는 실제 이번 달 재직자일 때만 선택하세요.

    ✓ 아래 가져오기 기록에 파일명과 적용 건수가 생기면 완료

  4. 4

    3. 직원 관리 · 4. 이번 달 급여

    자동 입력된 급여를 확인합니다

    1. 직원 관리에서 재직 여부, 지급주체, 월 기준시간을 확인합니다.
    2. 이번 달 급여에서 시간외시간과 수당을 확인합니다.
    3. 시간외수당은 자동 계산되므로 직접수정 칸은 보통 비워둡니다.
    4. 중도 입·퇴사처럼 확정 금액이 다를 때만 직접수정 칸을 씁니다.

    ✓ 지급계와 과세급여가 직원별로 표시되면 완료

  5. 5

    5. 보험·공제

    보험과 세금 자동값을 확인합니다

    1. 국민연금·건강보험·장기요양·고용보험 칸 아래의 자동 금액을 확인합니다.
    2. 소득세와 지방소득세는 과세급여로 자동 계산됩니다.
    3. 연말정산이나 기타공제가 있으면 해당 칸만 확인합니다.
    4. 보험 파일 3종이 모두 들어오면 보험 확인도 자동 체크됩니다.

    보험 칸에 숫자를 직접 쓰면 자동값보다 직접 쓴 금액이 우선합니다. 특별한 사유가 없으면 비워두세요.

    ✓ 모든 재직자의 보험 확인에 체크가 있으면 완료

  6. 6

    6. 검토·마감

    오류를 없애고 승인을 확인합니다

    1. 오류가 0인지 확인합니다.
    2. 주의사항이 있으면 내용과 근거를 확인합니다.
    3. 원장 검토, 재정이사 검토, 퇴직연금 확인에 체크합니다.
    4. 아직 마감하지 말고 먼저 7. 출력·백업으로 이동합니다.

    빨간 오류가 있으면 마감할 수 없습니다. 오류에 표시된 직원과 항목을 먼저 고칩니다.

    ✓ 오류 0, 승인 확인 2개 이상이 체크되면 출력 준비 완료

  7. 7

    7. 출력·백업

    필요한 문서와 백업을 저장합니다

    1. 급여명세서에서 1명 또는 전체 인쇄를 눌러 PDF로 저장합니다.
    2. 인건비 지급내역 CSV를 내려받아 원장에게 전달합니다.
    3. 세무사 급여정산 CSV를 내려받아 세무사에게 전달합니다.
    4. JSON 백업을 내려받아 접근 제한된 안전한 폴더로 옮깁니다.
    5. 6. 검토·마감으로 돌아가 이 급여월 마감을 누릅니다.

    ✓ PDF·CSV·JSON을 저장하고 마감 표시가 나오면 한 달 업무 완료

연차 기록은 이렇게 합니다

시간외 시트에 연차 현황이 있으면 자료 가져오기 때 함께 들어옵니다. 별도로 기록할 때는 연차 관리 → 사용 기록 추가를 누르고 직원, 사용일, 일수를 입력합니다. 잔여연차와 미사용수당 예상액은 자동 계산됩니다.

노란 경고가 나왔을 때

바로 적용하지 말고 급여월, 직원 연결, 서로 다른 파일의 금액을 확인합니다. 경고가 있어도 근거가 맞다면 적용할 수 있습니다.

잘못 적용했을 때

같은 원본 파일을 다시 넣으면 최신 값으로 덮어쓸 수 있습니다. 마감한 달이라면 먼저 마감 해제 확인이 나타납니다.

다른 컴퓨터로 옮길 때

기존 컴퓨터에서 JSON 백업을 받은 뒤 새 컴퓨터의 출력·백업 → JSON 복원을 사용합니다.

개인정보 주의

공용 PC에서는 사용하지 않습니다. 원본과 백업 파일은 접근 제한된 위치에 두고 이메일·메신저 전송 시 특히 주의합니다.
