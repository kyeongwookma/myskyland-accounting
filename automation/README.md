# 4대보험 포털 자료 반자동 다운로드

로그인은 담당자가 합니다. 그 뒤 메뉴 이동과 엑셀 다운로드, 파일 이름 정리, 내용 검증, `원본자료/YYYY-MM/` 저장을 스크립트가 합니다. 인증서와 비밀번호는 어디에도 저장하지 않습니다.

## 준비 (한 번만)

1. [Node.js LTS](https://nodejs.org) 설치. Chrome 또는 Edge가 설치돼 있어야 합니다.
2. Windows: `setup.cmd` 더블클릭. Mac: 이 폴더에서 `npm ci`.

## 매월 실행

Windows: `download.cmd` 더블클릭 후 급여월 입력. Mac:

```bash
node download.mjs 2026-08
```

Chrome이 열리면 화면 안내를 따릅니다.

1. 통합징수포털 로그인 → 터미널에서 Enter → 스크립트가 메뉴를 열고 건강보험·국민연금 산출내역을 받습니다.
2. 토탈서비스 로그인 → Enter → 고용보험 부과내역과 두루누리 지원금을 받습니다.
3. 국민연금 EDI 로그인 → Enter → 연금 두루누리 지원금을 받습니다.

스크립트가 버튼을 찾지 못한 단계는 "직접 해 주세요" 안내가 나옵니다. 그 단계만 손으로 누르면 나머지는 이어서 진행합니다. 다운로드 버튼을 직접 눌러도 파일은 스크립트가 받아 저장합니다.

끝나면 `원본자료/2026-08/`에 `2026-08_국민연금_산출내역.xlsx` 같은 이름으로 5개가 생기고, 각 파일이 앱이 인식하는 자료인지와 자료의 월이 급여월과 같은지 검증합니다. 이 폴더의 파일을 앱의 `자료 가져오기`에 끌어놓으면 됩니다.

- 검증에 실패한 파일은 `확인필요/`로 들어가고 실행이 실패로 끝납니다. 내용을 보고 다시 받으세요.
- 같은 자료를 다시 받으면 이전 파일은 `이전/`으로 옮겨져 최신 파일만 남습니다.

옵션: `--site jingsu|total|edi` 한 사이트만 실행. 브라우저는 Chrome, 없으면 Edge를 자동으로 씁니다. `--browser msedge`로 지정할 수도 있습니다.

## 포털이 구형 xls로 내려줄 때

앱은 xlsx만 읽습니다. 검증 결과에 "구형 xls 형식"이 나오면 Excel에서 열어 xlsx로 다시 저장하세요.

## 자동 클릭 늘리기

`sites.mjs`의 `find`에 적힌 메뉴 글자를 화면에서 정확히 하나만 찾을 때 자동으로 누릅니다. 못 찾거나 여러 개면 담당자에게 넘깁니다. 자동으로 넘어가게 하려면 담당자 PC에서 한 번 기록합니다.

```bash
npx playwright codegen --channel chrome https://si4n.nhis.or.kr/
```

로그인 뒤 매뉴얼 순서대로 클릭하면 선택자가 기록됩니다. 그 선택자를 `sites.mjs`의 해당 단계 `find`에 `{ css: "..." }`로 추가하세요. 기록 화면과 스크린샷에 개인정보가 남을 수 있으니 저장소에 올리지 마세요.

## 확인

```bash
node selftest.mjs
```

로컬 가짜 페이지에서 자동 클릭 → 다운로드 수집 → 검증 → 저장까지 실제 Chrome으로 확인합니다.

## 주의

- `.profile/` 폴더에 포털 세션 쿠키가 남습니다. 공용 PC에서는 쓰지 말고, 담당자 교체 시 이 폴더를 지우세요.
- 포털 화면이 바뀌면 그 달은 안내에 따라 손으로 누르고, 여유 있을 때 `sites.mjs`를 고치면 됩니다.
- 포털의 "부과월"과 앱의 "급여월"이 같은 달인지 화면에서 확인하세요.
